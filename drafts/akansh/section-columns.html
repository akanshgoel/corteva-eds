Section Columns

The EDS-native replacement for the legacy column-control when a column held a block (e.g. teaser cards) rather than plain content. Add a Section Metadata block with a "Style" of columns (2-up), or columns, columns-3 / columns, columns-4 for more columns. Blocks become grid cells; a heading authored before the blocks spans the row; columns stack on mobile.
